AgentForge

Four agents wired as an explicit state machine. After execution the critic can approve, send work back to the researcher, send it back to the executor, or escalate — four edges out of one node, which is why this is a graph and not a prompt chain.

This demo runs a deterministic backend rather than a language model, so it is free to host and identical on every run. That is deliberate: it makes the orchestration — routing, retries, the approval halt — observable on its own, which is the part worth showing. With an API key the same graph runs against a real provider. See the README for what the eval numbers do and do not establish.
