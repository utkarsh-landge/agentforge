AgentForge

Four agents — planner, researcher, executor, critic — wired as an explicit LangGraph state machine. The critic can approve, send work back to the researcher, send it back to the executor, or escalate. That is four edges out of one node, which is why this is a graph and not a prompt chain.

Source on GitHub API docs Runs the deterministic backend — no API key, no cost
Input

Set retries to 0 for the single-pass baseline.

Press Run the graph. Each line below is one node executing.

The demo runs a deterministic backend rather than a language model, so it is free to host and identical on every run. That makes the orchestration — routing, retries, the approval halt — observable on its own, which is the part worth showing. With an API key the same graph runs against a real provider; see the README.
